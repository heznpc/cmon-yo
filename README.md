# C'mon Yo!

오늘 동네에서 같이 움직이자.

React Web과 SwiftUI를 각각 제품 화면으로 유지하고, 하나의 Fastify 서버에서 API와 SSR이 같은 service를 사용합니다.

현재는 저장소 운영 기반을 준비한 단계입니다. Web·API·iOS 구현 및 실행 검증 결과는 아직 없습니다.

- [기여·브랜치·커밋 규칙](CONTRIBUTING.md)
- [PR1 수용조건](docs/pr1-acceptance.md)
- [제품·아키텍처 인계 문서](docs/CMON_YO_FINAL_HANDOFF.md)

각 PR은 구현, 자동 테스트, 실제 실행 QA, 발견한 문제의 수정과 재확인까지 포함합니다. 실행하지 못한 항목은 완료로 표시하지 않습니다.
